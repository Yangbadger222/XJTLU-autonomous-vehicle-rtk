# 研究驾驶舱与人工模式

驾驶舱在统一入口 `system_active_road_research.launch.py` 内启动，默认
`http://127.0.0.1:8765`，仅监听本机。远端使用 SSH 转发到同一端口：

```bash
ssh -N -L 127.0.0.1:8765:127.0.0.1:8765 badger@100.88.131.52
```

replay / shadow / live 是启动时确定的环境。界面不能切换环境、开启串口、
改参数或直接写速度。默认 replay 关闭物理串口与研究任务执行。
不要在生产 ROS domain 启动测试。隔离入口设 `ROS_LOCALHOST_ONLY=1`，
使用任务指定 domain；保留原 FYP 与 ROS 日志隔离路径。

## 操作

1. 接管操作席。一个浏览器窗口持有一个操作席，另一个窗口不能抢占。
2. 观察当前里程计、健康、RTK、网格、TF、地图版本与阻塞原因。
3. 在原静止阈值下连续确认静止，点击复位。判据从原 master 源与哈希生成；
   测量静止不是物理制动验收。
4. 从已注册先验中选择不同的起点、终点并提交。等待真实任务服务确认。
5. 只有 live 的显式任务/执行器启动配置与测量条件齐备时，才能请求启动。
   原 RTK / stop_override / KEY / 手柄 / 物理急停继续独立仲裁。
6. 暂停、软件停止和“等待现场接管”都会撤销自主许可。接管等待不发送
   网页摇杆速度；现场人工控制使用原硬件。

操作席心跳、界面状态读取、后端或下游许可传输失效后保持停止。
传输恢复、RTK 恢复或竞争发布者退出不会自动重新使能；必须重新确认、复位、
启动。每条有序 `OperatorPermit` 带会话、环境和地图版本；旧序号不能续期。
证据地图正常更新时，地图/轨迹/许可版本需重新一致，不能使用旧快照执行。

浏览器隐藏时暂停自主任务并停止心跳。Escape 是软件停止快捷键。
软件停止不能代替物理急停；物理制动与原 X/KEY 行为仍需现场验收。

## 回放与显示

通过 `bag_catalog_path` 指定只读目录清单。目录扫描采用原始 CDR 哈希去重；
开播前另外重验 metadata、文件封存状态及完整存储 SHA，覆盖播放时间戳变化。
只播放 `/livox/lidar`、`/livox/imu` 与测量时钟，固定 1×。
不会播放录制速度、authority、TF 或旧算法 odom。
界面控制的暂停、恢复、结束只作用于它记录 PID 的回放进程组。

局部网格、许可区、车辆、轨迹和道路证据使用真实 ROS 输入。
显示网格降采样，不用于规划。未知地面保持未知；缺少外参、健康等价、
正地面或配准先验时明确阻塞。里程计不是车辆标定已完成的证据。

HTTP 只接受同源 Host/Origin、会话 cookie、窗口标识与 CSRF。
连接线程和读超时有界。界面不提供任意 topic、路径、命令或参数编辑。
不要将本机 HTTP 端口直接暴露到公网；需要新的网络部署时另行评估。

运行证据、测试使用的合成参数与实车待验收项见 `audit/optimization_v2/`、
`RESULTS.json` 与 `LIVE_ACCEPTANCE_CHECKLIST.md`。

回放暂停采用所属播放器进程组 SIGSTOP；恢复可能追赶暂停期间的调度时间。本轮暂停/恢复验证不等于恢复后严格墙钟匀速验证。
