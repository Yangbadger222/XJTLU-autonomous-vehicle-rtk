#### Reason

- **Survey Mode Autonomy**: Manual teleoperation was previously required to explore unknown environments and manually match map coordinates. Survey mode provides an autonomous exploration pipeline capable of querying an existing map database to verify if an environment is already mapped or requires pure mapping.
- **TF Authority & Localizer Coordination**: In earlier revisions, concurrent TF broadcasting or direct steps between AMCL and 3D LiDAR localizers caused severe `map -> odom` transform jumps (20+ cm), triggering NavFn planning failures in inflated obstacle zones and Foxglove visualization flickering.
- **Multi-Tiered Safety Assurance**: Uncontrolled vehicle motion could occur if the host computer stalled, navigation crashed, or serial communication dropped while nonzero velocities were latched. Furthermore, partial collision slowdown could trap the chassis in high-torque stall conditions during turning maneuvers.
- **Operator Workflow & Telemetry**: Operators lacked a high-level, human-readable navigation interface and real-time visualization tools to dispatch named goals (for example, "PB414") and monitor navigation lifecycle status in Foxglove Studio.
- **Indoor Map Integrity & 2D/3D Consistency**: Raw 2D occupancy grids and 3D PCD point clouds often had unknown coordinate offsets and transient sensor noise speckles. A formal map bundle contract with quantitative validation gates (RMSE, overlap ratio) was essential for reliable lifelong localization and navigation.

#### Effect

- **Unified Exploration & Navigation Workflows**: Survey and Travel modes can be launched with single, standardized commands (`system_survey.launch.py`, `system_travel.launch.py`), handling autonomous exploration, map matching, and destination navigation end-to-end.
- **Smooth, Jump-Free Localization**: `prior_map_tf_authority` ensures seamless, rate-limited SE(2) transform transitions, completely eliminating AMCL/3D localizer fighting and preventing planner self-locking.
- **Guaranteed Fail-Closed Safety**: Any sensor dropout, localization degradation, navigation stall, or serial disconnect immediately triggers zero-velocity stops at both the ROS node level (`localization_cmd_gate`, `serial_twistctl`) and the embedded hardware level (RM C-Board 500ms watchdog).
- **Streamlined Operator Experience**: Operators can dispatch goals by name or via Foxglove 2D goal poses with real-time feedback, visual markers, and graceful preemption/cancellation.
- **Automated, High-Quality Map Bundles**: Single-command session saving produces validated, reproducible indoor map bundles with clean 2D occupancy grids and precisely aligned 3D point cloud descriptors.
- **Clean Build Pipeline**: Eliminated deprecation warnings and CMake policy notices across all workspace packages during `colcon build`.
